What example.com actually is

Three things to understand before you reference, cite, or test against this domain.

Reserved for documentation

Set aside by IANA specifically so writers, developers, and educators have a safe, neutral domain to use in examples — without pointing to a live, functioning site.

Not a functional service

There's no product, no booking system, and no team behind this address. It should never be used for testing scripts, monitoring, or live integrations.

Referenced worldwide

Used in technical writing, language exams, and research across the web as a universal, multilingual stand-in — precisely because it carries no commercial meaning.
