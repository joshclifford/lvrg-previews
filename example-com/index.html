What example.com actually is

No services, no storefront — just three quiet facts worth knowing before you reference it anywhere.

01

Reserved, not operational

example.com is set aside by IANA specifically so it can appear in documentation, tutorials, and sample code without being mistaken for a real, running service.

02

Free to use in examples

Writers and educators can use example.com in instructions, manuals, and demos without requesting permission — that's the entire reason it was created.

03

Not for testing or monitoring

It's a reference point, not infrastructure. example.com should never be used as a target for uptime checks, load tests, or production traffic.
